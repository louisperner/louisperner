## How I work

- **The whole path.** Idea, prototype, production and the server it runs on. I run my own infrastructure, so "done" means deployed, not merged.
- **Ship early.** Something working in front of real people teaches more than a perfect plan does.
- **Open the box.** I build my own tools, so a project never waits on a black box I cannot open.

## What I build

| | |
|---|---|
| **Products** | Web and mobile end to end: product thinking, design, code, deploy. Swift and Flutter on mobile, WordPress, Next.js and plain JavaScript on the web. |
| **AI engineering** | Claude and custom LLM features, agents, evals, MCP servers. Most of my daily tools now run on Claude Code. |
| **Games and 3D** | Unity, SwiftUI, Three.js and Blender. Mechas, spaceships, RTS prototypes, desktop cockpits. |

## Open source

| Project | What it is |
|---|---|
| [TraduzaJa](https://github.com/datamonkeys/TraduzaJa) | macOS menu bar translator. Select text, press ⌃⇧T, it is replaced in place. Runs on Claude Code, no API key. |
| [AstroMCP](https://github.com/louisperner/AstroMCP) | MCP server with read-only access to public astronomy archives (TNS, SIMBAD, Gaia, ZTF, Rubin). |
| [CacaSN](https://github.com/louisperner/CacaSN) | Supernova hunter for the public ZTF alert stream, with Transient Name Server check. |
| [CacaZoo](https://github.com/louisperner/CacaZoo) | Automatic triage for Zooniverse projects: brown dwarfs, active asteroids, transients. |
| [desktop-ship](https://github.com/louisperner/desktop-ship) | Transparent sci-fi cockpit overlay for your desktop, driven by AI agents through MCP. |
| [dm-webhooks](https://github.com/louisperner/dm-webhooks) | Signed WooCommerce order events to any webhook, with retries and delivery log. |
